# Invoicing Constitution

## Core Principles

### I. Data stays in the EU tenant (NON-NEGOTIABLE)
Customer personal data and invoice documents MUST NOT be sent to any third-party service
unless that service is covered by an approved data-processing agreement (DPA).
Approved DPAs today: **none**. Adding a provider requires a signed DPA approved by the DPO.

### II. Simplicity
One deployable service, PostgreSQL storage, no message brokers.
